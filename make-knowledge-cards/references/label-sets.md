# Card label sets

Use the label set for the source language so a card set reads naturally. Keep the labels identical across every card in a set.

For a language not listed here, translate the four English labels directly.

## English (default)

Header:

```markdown
# Knowledge cards: <title>

Source: <pasted article | file path> | Cards: <N>
```

Card:

```markdown
## Card 1: <title>
- **Core knowledge**: ...
- **Explanation**: ...
- **Example or self-test**: ...
```

Count note for short sources: `This article contains only <N> independent knowledge points, so it gets <N> cards.`
Missing information: `<item> is not stated in the source.`

## Chinese (Simplified)

Header:

```markdown
# 知识卡片：<标题>

来源：<粘贴的文章 | 文件路径> ｜ 卡片数：<N>
```

Card:

```markdown
## 卡片 1：<标题>
- **核心知识**：...
- **简明解释**：...
- **例子或自测**：...
```

Count note for short sources: `本文只包含 <N> 个独立知识点，因此输出 <N> 张卡片。`
Missing information: `原文未说明：<缺失的内容>`
